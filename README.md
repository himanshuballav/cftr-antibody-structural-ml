\# CFTR Antibody Structural Machine Learning



Computational workflow for antibody structural bioinformatics,

standardized CDR mapping, protein–protein interaction analysis,

feature engineering, and machine-learning classification.



\## Workflow



Antibody sequence input  

→ Structure prediction  

→ IMGT numbering and CDR mapping  

→ Structural/interface analysis  

→ Feature engineering  

→ Machine-learning modeling  

→ Interpretation and visualization



\## Tools



\- Python

\- pandas

\- NumPy

\- SciPy

\- scikit-learn

\- Matplotlib

\- Biopython

\- IgFold

\- ANARCI

\- ChimeraX

\- HADDOCK



\## Data Availability



Antibody sequences, antigen sequences, experimental measurements,

structural files, and unpublished results are not included in this

repository because they contain confidential or unpublished research data.



This repository contains the computational workflows, analysis scripts,

environment information, and documentation.
